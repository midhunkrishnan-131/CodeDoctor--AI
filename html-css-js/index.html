CodeDoctor AI Guide & Architecture

Understanding AI Modes, Execution Sandboxing, and Debugging Workflow

Two Core AI Diagnosis Modes

Mode A: Complete Answer Mode

Designed when you need the complete fix immediately. Identifies the root cause, categorizes bugs (Off-by-one, ZeroDivision, Recursion, Syntax), generates the complete corrected code with a 1-click Apply to Editor button, and provides edge-case test cases.

Mode B: Logic Suggestion Mode

Socratic mentoring mode. Strictly prohibits revealing the full solution code. Instead, it guides you with mental models, logical hints, guiding questions, and step-by-step reasoning so you can solve the bug independently.

Execution Sandbox & Safety

User scripts run in an isolated subprocess with active timeout detection (2–15s configurable), standard input stream piping, and microsecond execution time measurements. Standard Python libraries are supported.
