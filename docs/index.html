CodeDoctor AI

An in-browser Python workspace for running a snippet and reading a diagnosis of what went wrong — with dual AI modes, a code health bar, and challenge presets.

Open live demo View on GitHub Run locally

What you get in the browser demo

  • Full workspace UI (editor, terminal, diagnosis panels, challenges)
  • Offline simulation so you can explore the product without a server
  • Optional local backend for real Python execution and Groq/Gemini diagnosis

Dual AI modes

Complete Answer for a full fix, or Logic Suggestion for Socratic hints that withhold the solution.

Local Python sandbox

Run snippets with timeout, stdin, and health checks — then diagnose from the same page.

Open source

React/Vite frontend, Express or FastAPI API, and a standalone HTML/CSS/JS demo in the repo.
